# 功能码
- **01 (读线圈 - Read Coils)**
    
    - **作用**：**读取一组开关的输出状态**。通常用于读取 PLC 的输出继电器状态，或者你想知道某个执行器（如阀门、电机）目前是开还是关。
        
    - **特点**：因为是位（1bit），所以返回的数据会被“打包”。比如你一次读 10 个开关，返回不会占 10 个字节，而是只占 2 个字节（8个位凑1个字节）。
- **02 (读离散输入 - Read Discrete Inputs)**
    
    - **作用**：**读取一组外部输入的开关状态**。通常用于读取物理按钮、行程开关、限位开关的状态。
        
    - **区别**：和 01 一样都是读开关，区别在于**01 读的是“输出”（设备可以修改的），02 读的是“物理输入”（外部接进来的，设备只能看不能改）**。
- **03 (读保持寄存器 - Read Holding Registers)**
    
    - **作用**：**这是最最常用的指令！** 读取设备内部的**数值型数据**。比如读取当前的温度值、压力值、设定参数、电机转速等。
        
    - **特点**：一次可以连续读取多个寄存器（比如一次读 10 个数据）。返回的数据是 16 位的整数。
- **04 (读输入寄存器 - Read Input Registers)**
    
    - **作用**：读取来自传感器的**原始模拟量数值**。
        
    - **区别**：03 和 04 都是读数值，但**03 读的是“可修改的参数”（如设定温度），04 读的是“只读的测量值”（如当前实际温度）**。
- **05 (写单个线圈 - Write Single Coil)**
    
    - **作用**：**控制单个开关的开或关**。比如你要单独打开 1 号继电器。
        
    - **特别说明**：Modbus 规定，**写入 ON（开）的值必须是 `0xFF00`，写入 OFF（关）的值必须是 `0x0000`**。如果你发送 `0x0001` 它是不会认的。
        
    - **响应**：设备收到后，会把请求原封不动地回复给主机，表示“我收到了，并且执行了”。
- **06 (写单个寄存器 - Write Single Register)**
    
    - **作用**：**修改一个具体的数值参数**。比如你要把某个设备的运行速度设置为 500，或者把 PID 的设定温度改为 100.5 度。
        
    - **特点**：只写一个数，响应也是原样返回。
- **15 (写多个线圈 - Write Multiple Coils)**
    
    - **作用**：**一次性控制一组（多个）开关的状态**。比如你要同时“开启 1号、关闭 2号、开启 3号”继电器。
        
    - **为什么要有这个？** 如果你用功能码 05 挨个发指令，网络延迟会很严重。用 15 可以一次性把几十个开关的状态打包发给设备，效率极高。请求包中会有一个“字节数”告诉设备后面跟着多少数据。
- **16 (写多个寄存器 - Write Multiple Registers)**
    
    - **作用**：**一次性批量写入多个数值参数**。
        
    - **适用场景**：比如你需要配置一个变频器的“加速时间、减速时间、最大频率”这三个参数，如果挨个发 06 指令就很慢。用 16 指令，你可以一次发一个数据包，把这 3 个数值一口气传给设备。


# 报文格式
- 站地址（占一个字节）
- 功能码（占一个字节）
- 数据部分（占N个字节）
		读取
			起始地址
			长度
		写入
			起始地址
			数据
- 校验部分（占两个字节）
