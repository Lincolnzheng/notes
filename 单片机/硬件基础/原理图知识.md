原理图观看
可以分为从CPU到外设和从外设到CPU，软件工程师的主要目的是看哪些连到CPU上，能通过哪些[[引脚类型|引脚]]控制外设，怎么配置外设等。

| 标记        | 含义          | 常见用途     |
| --------- | ----------- | -------- |
| U         | 芯片          | 单片机、稳压器  |
| R         | 电阻          | 限流、上拉、下拉 |
| C         | 电容          | 滤波、去耦    |
| D / LED   | 二极管 / 发光二极管 | 保护、指示    |
| Y / X     | 晶振          | 提供时钟     |
| SW / KEY  | 开关 / 按键     | 用户输入、复位  |
| VCC / VDD | 电源正极        | 给器件供电    |
| GND / VSS | 地           | 电压的参考点   |
