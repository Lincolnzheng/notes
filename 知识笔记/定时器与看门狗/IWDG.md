# IWDG：独立看门狗

> [!summary] 核心记忆
> **LSI 独立时钟 → 计数器递减 → 正常运行时及时喂狗 → 超时后硬件复位。**

## 1. 作用与工作原理

**IWDG（Independent Watchdog，独立看门狗）** 是保护系统的外设，用于在程序异常、无法正常喂狗时触发系统复位。

- **时钟源是 LSI**：独立于主时钟，主时钟失效时仍能工作。
- **计数器递减**：计数结束时产生复位。
- **喂狗就是重装载**：把 `IWDG_RLR` 中的值重新装入计数器，让计数重新开始。

### 硬件启动与软件启动

在 STM32 的 IWDG 配置语境中，“硬件／软件看门狗”通常指**启动方式**，由选项字节选择：

| 模式 | 启动方式 |
| --- | --- |
| 硬件启动 | 按选项字节配置自动启动 |
| 软件启动 | 由程序写入启动键值 |

**两种启动方式下，超时复位都由 IWDG 硬件完成**，不能理解成“软件启动后由软件执行复位”。参考：[ST 的 STM32F4 HAL 驱动说明](https://github.com/STMicroelectronics/stm32f4xx-hal-driver/blob/master/Src/stm32f4xx_hal_iwdg.c)。

## 2. 超时时间

超时时间主要取决于 **LSI 频率、预分频系数、重装载值**。

原图中的估算关系为：

$$
T_{out} \approx \frac{psc \times rlr}{f_{LSI}}
$$

| 符号 | 含义 |
| --- | --- |
| $T_{out}$ | 看门狗超时时间，单位为秒 |
| $f_{LSI}$ | LSI 时钟频率，单位为 Hz |
| $psc$ | 实际分频倍数，不是寄存器编码 |
| $rlr$ | 重装载寄存器的值 |

> [!note] 使用公式时注意
> 原图适合估算；精确计数周期和分频编码应查对应芯片的参考手册，不要把图中的 `psc = 4 × 2^per` 无条件套到所有编码或型号。
> LSI 频率存在偏差，因此实际超时时间也会变化，喂狗周期应留出余量。[ST HAL 驱动说明](https://github.com/STMicroelectronics/stm32f4xx-hal-driver/blob/master/Src/stm32f4xx_hal_iwdg.c)

## 3. 寄存器与关键键值

| 寄存器 | 作用 |
| --- | --- |
| `IWDG_KR` | 键寄存器，用于启动、解锁配置和喂狗 |
| `IWDG_PR` | 设置预分频系数 |
| `IWDG_RLR` | 设置重装载值 |
| `IWDG_SR` | 查看配置寄存器的更新状态 |

写入 `IWDG_KR` 的三个关键值：

| 键值 | 作用 |
| --- | --- |
| `0xCCCC` | 启动 IWDG |
| `0x5555` | 解除配置寄存器的写保护 |
| `0xAAAA` | 重装载计数器，即喂狗 |

记忆：**C 启动，5 解锁，A 喂狗。**

## 4. HAL 配置与使用

### 初始化流程

按原图和 STM32F4 HAL 的流程整理：

1. 启动 IWDG：向 `IWDG_KR` 写入 `0xCCCC`。
2. 解锁配置：向 `IWDG_KR` 写入 `0x5555`。
3. 设置 `IWDG_PR` 和 `IWDG_RLR`。
4. 等待 `IWDG_SR` 中的相关更新标志清零。
5. 写入 `0xAAAA`，完成一次喂狗。

上述操作由 `HAL_IWDG_Init()` 封装完成；它既配置参数，也启动看门狗。运行过程中调用 `HAL_IWDG_Refresh()` 喂狗。[ST HAL 实现](https://github.com/STMicroelectronics/stm32f4xx-hal-driver/blob/master/Src/stm32f4xx_hal_iwdg.c)

| HAL 函数                     | 作用                    |
| -------------------------- | --------------------- |
| `HAL_IWDG_Init(&hiwdg)`    | 初始化参数、启动 IWDG，并重装载计数器 |
| `HAL_IWDG_Refresh(&hiwdg)` | 将重装载值重新装入计数器          |

## 5. 复习要点

- **独立在哪里？** 使用 LSI，不依赖主时钟。
- **为什么会复位？** 程序未及时喂狗，计数结束。
- **喂狗改了什么？** 重装载计数器，不是重新设置预分频系数。
- **初始化后还要做什么？** 在正常运行路径中按时喂狗。
- **配置是否能直接跨型号照搬？** 不能；LSI 参数、分频范围及可选功能应查对应芯片手册。
