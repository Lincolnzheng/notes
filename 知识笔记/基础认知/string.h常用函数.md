# string.h 常用函数

使用前包含头文件：`#include <string.h>`。

| 函数                      | 参数说明                                                       | 简单介绍                                            | 注意事项                                       |
| ----------------------- | ---------------------------------------------------------- | ----------------------------------------------- | ------------------------------------------ |
| `strlen(s)`             | `s`：待计算长度的字符串。                                             | 返回字符串长度，不包括末尾的 `'\0'`。                          | 字符串必须以 `'\0'` 结束；统计的是字节数。                  |
| `strcpy(dest, src)`     | `dest`：目标缓冲区；`src`：源字符串。                                   | 将源字符串复制到目标，包括末尾的 `'\0'`。                        | 目标空间必须足够，源、目标不能重叠。                         |
| `strncpy(dest, src, n)` | `dest`：目标缓冲区；`src`：源字符串；`n`：写入目标的总字节数。                     | 最多复制源字符串的 `n` 个字符；源较短时补零到 `n` 字节。               | 源长度大于或等于 `n` 时，不会自动添加 `'\0'`；源、目标不能重叠。     |
| `strcat(dest, src)`     | `dest`：已有字符串的目标缓冲区；`src`：待追加的字符串。                          | 将源字符串追加到目标字符串末尾。                                | 目标必须已有结束符，且空间足够；源、目标不能重叠。                  |
| `strncat(dest, src, n)` | `dest`：已有字符串的目标缓冲区；`src`：待追加的字符串；`n`：最多追加的字符数。             | 最多追加 `n` 个字符，再添加 `'\0'`。                        | `n` 不包含最后添加的结束符，也不是目标总容量；源、目标不能重叠。         |
| `strcmp(s1, s2)`        | `s1`、`s2`：待比较的两个字符串。                                       | 相同返回 `0`；`s1` 小于或大于 `s2` 时，分别返回负数或正数。           | 区分大小写，按字节比较；返回值不一定是 `-1` 或 `1`。            |
| `strncmp(s1, s2, n)`    | `s1`、`s2`：待比较的两个字符串；`n`：最多比较的字符数。                          | 最多比较前 `n` 个字符，遇到结束符也会停止；返回值含义同 `strcmp`。        | 返回 `0` 只表示比较部分相同。                          |
| `strchr(s, c)`          | `s`：待查找的字符串；`c`：要查找的字符，如 `'='`。                            | 查找字符第一次出现的位置。                                   | 返回该位置的指针，找不到返回 `NULL`。                     |
| `strrchr(s, c)`         | `s`：待查找的字符串；`c`：要查找的字符，如 `'.'`。                            | 查找字符最后一次出现的位置。                                  | 返回该位置的指针，找不到返回 `NULL`。                     |
| `strstr(s, sub)`        | `s`：待查找的字符串；`sub`：要查找的子字符串，如 `"OK"`。                       | 查找子字符串第一次出现的位置。                                 | 返回该位置的指针，找不到返回 `NULL`。                     |
| `strtok(s, delim)`      | `s`：首次传入可写字符串，后续传入 `NULL`；`delim`：分隔字符集合，如 `",;"` 表示逗号或分号。 | 按分隔字符拆分字符串，每次返回一个字段的指针，结束时返回 `NULL`。            | 会修改原字符串；跳过空字段，内部保存解析状态，不适合嵌套或并发调用。         |
| `strspn(s, accept)`     | `s`：待扫描的字符串；`accept`：允许的字符集合。                              | 返回开头连续属于该集合的字符数。                                | 如 `strspn("123abc", "0123456789")` 返回 `3`。 |
| `strcspn(s, reject)`    | `s`：待扫描的字符串；`reject`：遇到其中任意字符就停止的字符集合。                     | 返回开头连续不属于该集合的字符数。                               | 如 `strcspn("ABC,DEF", ",")` 返回 `3`。        |
| `strpbrk(s, accept)`    | `s`：待查找的字符串；`accept`：要查找的字符集合。                             | 查找第一个属于该集合的字符。                                  | 返回该位置的指针，找不到返回 `NULL`。                     |
| `memcpy(dest, src, n)`  | `dest`：目标内存地址；`src`：源内存地址；`n`：复制的字节数。                      | 从源地址复制 `n` 字节到目标地址。                             | 源、目标不能重叠；不会自动添加 `'\0'`。                    |
| `memmove(dest, src, n)` | `dest`：目标内存地址；`src`：源内存地址；`n`：复制的字节数。                      | 从源地址复制 `n` 字节到目标地址。                             | 允许源、目标内存区域重叠。                              |
| `memset(s, c, n)`       | `s`：待填充的内存地址；`c`：填充值；`n`：填充的字节数。                           | 将前 `n` 字节填充为转换成 `unsigned char` 后的 `c`。         | 按字节填充；给整数数组填充 `1`，不代表每个整数都是 `1`。           |
| `memcmp(s1, s2, n)`     | `s1`、`s2`：待比较的两个内存地址；`n`：比较的字节数。                           | 按无符号字节比较前 `n` 字节；相同返回 `0`，否则按大小返回负数或正数。         | 可比较二进制数据；不宜直接用于判断结构体字段是否相等。                |
| `memchr(s, c, n)`       | `s`：待查找的内存地址；`c`：要查找的字节值；`n`：查找范围的字节数。                     | 查找前 `n` 字节中第一次出现的指定字节，`c` 会转换为 `unsigned char`。 | 返回该位置的指针，找不到返回 `NULL`。                     |

> 字符串函数依靠 `'\0'` 判断结束；`mem` 系列按指定字节数操作，可处理包含 `0x00` 的二进制数据。长度参数 `n` 的类型为 `size_t`，具体含义见表格。以上函数通常不会检查缓冲区容量，使用时需自行保证访问范围有效。
